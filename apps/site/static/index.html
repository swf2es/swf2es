    What to expect

    • ActionScript 3 (AVM2) runs, compiled to JavaScript as the SWF loads. Video and Stage3D are not there yet.
    • ActionScript 1 and 2 (AVM1) run too, including clips and their events, buttons, mouse and keyboard input, drawing, text fields, sound, filters and blend modes, BitmapData, SharedObject, and loading with loadMovie, MovieClipLoader and LoadVars. HTTP remoting through NetConnection is supported. Compatibility is still incomplete: LocalConnection is not implemented, and some SWFs have rendering or interaction differences.
    • No sockets. A browser cannot open TCP connections and this static site runs no relay, so Socket and XMLSocket fail as refused.
    • Cross-origin loads. A SWF by URL, and whatever it loads from another site, arrive only where that server allows it (CORS headers).
    • Files you open play as if from this site's local/ folder, by their names: what one loads by a relative URL is not there, and each name keeps its own saved data (SharedObjects) in this browser.
    • The page keeps the code it compiled in this browser's IndexedDB, so a SWF starts faster next time.
    • ActionScript 3 links against avmplus' builtin.abc (MPL-2.0) and swf2es's own playerglobal, never Adobe's. See the licences.
