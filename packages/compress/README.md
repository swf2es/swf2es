# @swf2es/compress

Synchronous zlib and LZMA for SWF bodies, bitmaps and `ByteArray`, in one
WebAssembly module that imports nothing. zlib 1.3.2 is a pinned submodule
in [`vendor/zlib`](../../vendor/zlib); the LZMA SDK 26.05's encoder,
`C/LzmaEnc.c`, `C/LzFind.c` and the headers they include, all public domain,
is checked in under [`vendor/lzma-sdk`](../../vendor/lzma-sdk), whose README
names the release and each file's hash.
LZMA decoding is `lzma.zig`, after the LZMA SDK's specification decoder.
The C adapter (`compress.c`), the few libc declarations it needs
(`include/`), the decoder and the TypeScript wrapper live here; upstream
sources stay unchanged.

- `inflate(data, raw, limit)` inflates a zlib or raw deflate stream to at
  most `limit` bytes, stopping at the stream's end.
- `deflate(data, level, raw)` deflates as zlib does at that level.
- `lzmaDecode(stream, size)` decodes an LZMA stream, its 5 property bytes
  first, to `size` bytes or to its end marker.
- `lzmaEncode(data)` writes `ByteArray`'s LZMA: properties, an 8-byte
  length and the stream, at level 9 with a 1 MB dictionary as avmplus, or
  a smaller one for less data.

Decoders return a status, the bytes decoded (also on a failure, up to it)
and how much input they read, and can leave room before their output so
that a SWF's header needs no second copy.

The module is compiled synchronously on first use from the base64 in
`src/binary.ts`. Each call resets a bump arena in the module's memory,
copies its input in and its output out; outputs of unknown size grow in
place at the arena's top, so they are never copied as they grow. Memory
never shrinks, so an instance whose memory grew past 8 MiB, which LZMA
encoding of more than a few hundred KB does, is dropped after its call and the next call
instantiates a new one.

The binary is checked in, so ordinary builds need no compiler. `pnpm build`
verifies its input digest. To rebuild after changing the sources or the
upstream pins:

```sh
pnpm --filter @swf2es/compress build:wasm
```

This runs Zig 0.17.0, from the PATH or else downloaded once into
`~/.cache/swf2es` and checked against its SHA-256. CI rebuilds and compares
the generated bytes. `LICENSE.zlib` and `LICENSE.lzma-sdk` accompany
published builds; zlib is under the zlib license, the LZMA SDK files are in
the public domain, and the rest is Apache-2.0.
